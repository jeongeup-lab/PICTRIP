# PicTrip 유사 프로젝트 홈 화면 갤러리

기준 시각: 2026-08-09 KST

PicTrip과 콘셉트가 겹치는 핵심 후보 7개의 공개 홈 화면만 모은 비교 자료다. 라이브 배포가 있으면 실제 렌더링을 캡처했고, 공개 UI가 없으면 추측해서 그리지 않고 증거 상태를 표시했다.

| 프로젝트 | 상태 | 홈 화면 출처 | 캡처 파일 | 메모 |
|---|---|---|---|---|
| [TripCraft Korea](https://github.com/40s-AI-Study/tourism-service-lab-v2) | `REPO MOCKUP` | [GitHub Pages 프로토타입](https://40s-ai-study.github.io/tourism-service-lab-v2/prototypes/tripcraft-korea/) | `screenshots/tripcraft-home.png` | 배포 제품이 아니라 제출용 인터랙티브 프로토타입 |
| [NextSpot](https://github.com/NextSpot-knu/NextSpot) | `LIVE` | [Main](https://nextspot-nu.vercel.app/main) | `screenshots/nextspot-home.png` | 지도·필터·추천 패널이 보이는 메인 홈 |
| [Gangneung Node](https://github.com/Altair5869/gangneung_node) | `LIVE` | [Home](https://gangneung-node.vercel.app/) | `screenshots/gangneung-node-home.png` | 워케이션 랜딩과 AI 동선 진입 CTA |
| [TapGyeong](https://github.com/keilvher1/tapgyeong-web) | `LIVE` | [Home](https://tapgyeong-web.vercel.app/) | `screenshots/tapgyeong-home.png` | 모바일 폭 중심 NFC 관광 랜딩 |
| [TripPing](https://github.com/enhn16/TripPing-frontend) | `NO PUBLIC UI` | 공개 홈 없음 | `screenshots/tripping-home.png` | 공개 저장소에는 README와 convention 문서만 존재 |
| [에움길](https://github.com/GreedyLabs/eumgil) | `LIVE` | [Home](https://xn--wk0bk16buua.xn--3e0b707e/) | `screenshots/eumgil-home.png` | 현재 `COMING SOON · 2026` 랜딩 |
| [IT-DA](https://github.com/hyunsoo0040/tourism-data-contest) | `LIVE` | [GitHub Pages](https://hyunsoo0040.github.io/tourism-data-contest/) | `screenshots/it-da-home.png` | 여행 유형·사진 분위기 입력을 설명하는 홈 |

비교 페이지는 [`index.html`](index.html)이다. 이미지를 누르면 원본 PNG를 확인할 수 있다.
