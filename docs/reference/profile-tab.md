# 마이 탭 화면 명세

> 마이 탭과 그 하위 화면(스크랩·설정·계정·약관)의 구성 요소·수치·상태 조회표.
> 다크 전환 배경은
> [ADR 0015](../adr/0015-travel-and-profile-go-dark-on-one-map.md).
> 색·간격 정본은 `mobile/src/constants/theme.ts`.

탭은 홈 · 탐색 · 여행 · **마이** 4개. 마이 탭만 이 문서의 범위다.

## 라우트

| 경로 | 파일 | 역할 |
|---|---|---|
| `/(tabs)/profile` | `app/(tabs)/profile.tsx` | 히어로 + 통계 + 스크랩 레일 + 설정 그룹 |
| `/saved` | `app/saved.tsx` | 스크랩 전체 — 2열 앨범, 타일 하트로 해제 |
| `/settings` | `app/settings.tsx` | 기기 권한 — 위치·사진·카메라 OS 상태 |
| `/account` | `app/account.tsx` | 닉네임·이메일·가입일 · 로그아웃 · 회원 탈퇴 진입 |
| `/account/delete` | `app/account/delete.tsx` | 회원 탈퇴 전체 화면 — 확인 체크 후 탈퇴 |
| `/consent` | `app/consent.tsx` | 동의 내역 — 읽기 전용 2개 동의 상태 |
| `/legal` | `app/legal/index.tsx` · `app/legal/[slug].tsx` | 문서 목록·본문 |

설정과 계정을 마이 본화면에서 갈라낸 것은 본화면이 "기록"과 "관리"를 한 스크롤에
쌓고 있었기 때문이다. 관리 항목은 자주 쓰지 않으므로 한 단계 아래로 내린다.
탈퇴는 그중에서도 되돌릴 수 없는 행동이라 별도 전체 화면으로 분리해 확인을
강제한다.

## 마이 본화면

| 층 | 내용 |
|---|---|
| 내비 | `마이` 21/800 + 우측 `settings` 아이콘 → `/settings` |
| 히어로 | `ProfileHero`(로그인) 또는 `GuestHero`(게스트) |
| 통계 | `StatTiles` 3칸 |
| 스크랩 | `SectionTitle` + `SavedRail`, 비어 있으면 `EmptyBoard` |
| 설정 | `ListGroup` — 계정(로그인) · 기기 권한 · 동의 내역(로그인) · 약관·정책 · 문의 · 앱 버전 |

**히어로에 커버 이미지를 깔지 않는다.** 스크랩 첫 장을 배경으로 쓰면 어떤 장소가
뽑힐지 사용자가 통제할 수 없고, `SpotCard` 에 저작권 구분이 없어 어떤 이미지가
들어올지도 화면이 알 수 없다.

### 통계 타일

| 타일 | 값 | 출처 |
|---|---|---|
| 스크랩 | 저장 수 | `useSavedList()` |
| 지역 | 저장한 곳의 시·도 distinct | `addr1` 첫 토큰 |
| 함께한 날 | 가입일부터 오늘까지, 가입일 포함 | `user.createdAt` |

**세션 로컬 값은 타일에 올리지 않는다.** `질문 수`·`사진검색 수` 는 메모리
대화 스토어에서 세어 앱을 껐다 켜면 0으로 돌아갔다 — 서버가 주지 않는 숫자를
지어내느니 뺀다.

목록이 `SAVED_PAGE_LIMIT`(60)에서 잘리면 값에 `+` 를 붙인다(`60+`). 커서를
끝까지 따라가는 일은 스크랩 목록 전체가 같은 제약을 공유하므로 따로 다룬다.

## 스크랩 (`/saved`)

| 배치 | 2열 앨범(`SavedCard`) — 정사각 이미지 + 아래 제목·`지역 · 분류` |
| 순서 | 서버가 준 순서(최근 저장 순) 고정 |
| 해제 | 타일 우상단 하트 |
| 되돌리기 | `Toast` `action`, `TOAST_UNDO_MS`(5초) |

**정렬 칩도 보기 전환도 없다.** `가까운 순`·`지역별`은 위치 권한과 정렬 상태를
끌고 들어오면서, 스크랩을 "다시 보려고 저장한 사진 더미"로 쓰는 실제 사용과
어긋났다. 사진이 곧 식별자이므로 앨범 한 겹으로 고정한다.

### 해제와 되돌리기

낙관적으로 타일을 지우고 되돌리기 토스트를 띄우되, 요청 결과에 따라 갈린다.

| 상황 | 결과 |
|---|---|
| DELETE 성공 | 되돌리기 유지 |
| DELETE 실패 | 목록 롤백 + `UNSAVE_FAILED`, 되돌리기 감춤 |
| 되돌리기 | DELETE 가 **가라앉은 뒤** 재저장 — 두 요청이 겹치면 POST 가 먼저 커밋돼 서버에 해제가 남는다 |
| 재저장 실패 | `RESAVE_FAILED` |

실패 알림은 **그 항목이 아직 현재 알림일 때만** 건다. A·B 를 잇달아 해제하고
B 의 토스트가 떠 있는데 느린 A 가 실패하면, 무조건 덮어쓸 경우 B 를 되돌릴
기회가 사라진다.

빈 상태는 안내 박스 + `탐색 열기`다. 마이 탭의 빈 스크랩 CTA와 `/saved`의 빈
스크랩 CTA 모두 `/explore`로 이동한다. `/saved`에는 **최근 본 곳**(로컬)도
함께 표시한다.

## 설정 (`/settings`)

| 행 | 내용 |
|---|---|
| 위치 · 사진 · 카메라 | 실제 OS 상태를 읽어 표시, 탭하면 기기 설정 |

권한은 `PermissionResponse.status` 로 읽는다 — `canAskAgain` 만 보면 사용자가
명시적으로 거절했는데 OS 가 재요청을 허용하는 경우가 `미설정` 으로 보인다.

설정 화면은 기기 권한만 담당한다. 약관·정책은 마이 본화면, 동의 내역은
`/consent` 로 나눠 담당한다.

## 계정 (`/account`)

닉네임·이메일·가입일은 **읽기 전용**이다 — 백엔드에 수정 엔드포인트가 없다.
같은 이유로 비밀번호 변경 행도 없다.

회원 탈퇴는 마이 본화면의 `회원 탈퇴` 행에서 진입하는 **별도 전체 화면**
(`/account/delete`)에서 진행한다. 삭제 항목 체크리스트와 확인 체크를 거쳐야
탈퇴 버튼이 활성화되고, 탈퇴 중에는 화면 이탈(뒤로가기 포함)이 차단된다.
스크랩 수는 **로드된 목록 기준**으로 적는다 — `saved?.length` 가 `SAVED_PAGE_LIMIT`
(60)에서 잘리면 60개까지 안내될 수 있다.

탈퇴 화면은 PicTrip에 저장된 스크랩, 소셜 로그인 연결 정보, 닉네임·이메일 등
계정 정보를 삭제 대상으로 안내한다. 방침에 없는 항목은 화면에서도 약속하지
않는다.

에러는 `err.code` 로 가른다(만료 세션 등). `message` 로 분기하지 않는다.

## 동의 내역 (`/consent`)

로그인 계정 전용 화면 — 약관·개인정보(필수)와 위치정보(선택) 2개 동의의 현재
상태만 보여준다. 기록이 없으면 `기록 없음`/`동의 안 함` 을 표시한다. 게스트는 로그인
유도 박스만 보고 기록을 보지 못한다. 재동의·수정 UI 는 없다.

위치 동의 행이 어긋나 있으면 포커스 시 `useLocationConsentSync` 가 서버 기록을
OS 권한에 맞춘다 — `/settings` 와 `/consent` 모두 같은 훅을 쓴다.

## 약관 (`/legal`)

문서 목록(이용약관 · 개인정보처리방침 · 위치기반서비스)만 담당한다. 내 동의
내역은 `/consent` 로 이동했다. 마케팅 수신 동의 항목은 consent API 에 없어
넣지 않는다.

**출처표시는 앱이 아니라 웹이 진다.** 앱 안의 `데이터 출처` 문서 행과 각주를
모두 걷어냈고, 공공누리 출처표시는 `pictrip.org/legal/data-sources` 가 전담한다.

## 세션 정리

로그아웃·탈퇴는 계정 범위 상태를 함께 비운다(`auth-store` 의 `clear()`).

- `saved` 쿼리 캐시
- `consents` 쿼리 캐시 — 남기면 다음 계정의 동의 화면이 앞 계정 값을 읽고,
  동기화 훅이 그 값을 새 계정에 PUT 할 수 있다
- 최근 본 곳(`recent-store`) — 남기면 다음 계정의 빈 스크랩 화면에 앞 사람이
  본 장소가 노출된다
