# 여행 탭 QA

> 지도 + 결과 패널 + 독 구조의 여행 탭을 출시 전 실기기에서 확인하는 체크리스트.
> 화면 정본은 [여행 탭 화면 명세](../reference/travel-tab.md).

## 목표

여행 탭의 11개 상태와 실패 복구를 iOS·Android에서 같은 기준으로 검증한다.
**자동 테스트가 못 잡는 것만 사람이 본다** — 레이아웃 겹침, 제스처, 실제 권한
다이얼로그, 키보드, 지도 WebView 왕복이 그렇다. 컴포넌트 단위 분기와 요청
payload 는 Jest 가 이미 잡으므로 여기서 다시 세지 않는다.

## 전제

- 최신 `dev` API에 연결한 개발 빌드와 비로그인·로그인 계정을 각각 준비한다.
- 위치 권한은 `미결정`, `허용`, `거절` 세 상태를 재현할 수 있어야 한다.
- JPEG, PNG, WebP, HEIC와 손상 이미지, 8MB 초과 이미지를 준비한다.
- 네트워크 정상·오프라인·느린 응답을 전환할 수 있어야 한다.
- 결과가 여러 지역에 흩어지는 질문(`제주에서 한적한 곳`)과 0곳으로 끝나는
  질문(`제주 실내 박물관`)을 하나씩 준비한다.
- 저장 결과는 마이 탭과 서버 조회로 교차 확인한다.

P0 실패는 병합·출시를 막는다. P1 실패는 담당자, 우회 방법, 수정 목표 버전을
기록해야 한다.

## 1. 11개 상태를 눈으로 확인한다

| ID | 우선순위 | 조건·동작 | 기대 결과 |
|---|---|---|---|
| TRV-001 | P0 | 좌표 있는 상태로 여행 탭을 처음 연다 | 지도가 화면을 채우고 **패널이 없다**. 독에 `사진`·`근처 카페`·`근처 맛집`·`근처 볼거리` 넷뿐 |
| TRV-002 | P0 | 위치 권한을 거절한 상태로 연다 | 칩 넷이 **그대로** 있다. `근처 카페`를 누르면 요청 없이 `위치를 켜면 내 근처를 찾아드려요` 토스트만 뜬다 |
| TRV-002b | P0 | 권한을 **허용한** 상태로 여행 탭을 열자마자 `근처 카페`를 누른다 | 좌표를 아직 읽는 중이면 `위치를 확인하는 중이에요` 다 — 거절한 것처럼 `위치를 켜면…` 이 뜨면 안 된다. 잠시 뒤 다시 누르면 요청이 나간다 |
| TRV-002c | P0 | 권한 미결정 상태에서 `근처 카페`를 눌러 OS 창에서 **허용**한 직후 다시 누른다 | 좌표를 받아오는 동안에도 `위치를 확인하는 중이에요` 다. `위치를 켜면…` 이 뜨면 안 된다 |
| TRV-003 | P0 | 권한 미결정 상태로 연다 | 칩 행 위에 `위치를 켜면 내 근처로 물어볼 수 있어요` 한 줄 + `켜기`. 칩을 눌러도 OS 권한 다이얼로그가 뜬다 |
| TRV-004 | P0 | `사진` 칩으로 사진을 첨부한다 | 칩 행 자리를 첨부 배너가 **대체**한다(둘이 함께 뜨지 않는다). 프라이머가 사라지고 placeholder 가 `지역이나 조건을 덧붙여 보세요` |
| TRV-005 | P0 | 질문을 보내고 응답이 오기 전까지 본다 | **패널이 올라오고** 안에 질문 한 줄 + 단계 스피너 + 스켈레톤 카드 2장, 지도 위에 검색 펄스가 돈다. 독은 입력 줄만 남고 전송·촬영이 비활성 |
| TRV-006 | P0 | 결과가 여러 곳인 답을 받는다 | 패널 안이 위에서부터 **첫 문장 → 카드 + 진행 바 → `{제목} 근처 카페`·`{제목} 근처 맛집`·`{제목} 근처 볼거리`** 순이다. 세 칩 모두 이름을 앞에 단다 |
| TRV-007 | P0 | 답변 문장의 셰브론을 누른다 | 나머지 문장이 펼쳐지며 **패널이 위로 자란다**. 카드·칩은 제자리고 독도 그대로다. 다시 누르면 접힌다 |
| TRV-008 | P0 | 카드를 옆으로 넘긴다 | 문맥 칩 셋의 이름이 **한꺼번에** 새 카드로 바뀐다(`천지연 근처 카페`…). placeholder 도 같이 바뀐다 |
| TRV-009 | P1 | 사진으로 물어 결과를 받는다 | 패널 답변 줄 왼쪽에 보낸 사진 썸네일이 붙고 카드 성질 칩이 `유사도 N%` 다 |
| TRV-010 | P0 | 스팟 상세에서 `{제목}에 대해 물어보기`를 누른다 | 패널에 그 카드 **한 장**이 뜨고 답변 문장과 `새 대화`가 없다. placeholder 와 문맥 칩 셋이 그 이름을 부른다 |
| TRV-011 | P0 | 0곳으로 끝나는 질문을 보낸다 | 실패가 아니다 — 답변이 처음부터 펼쳐져 있고 셰브론이 없다. 카드 자리가 통째로 빠져 패널이 얇아지고, 문맥 칩도 없다(`사진` + refine 만) |
| TRV-012 | P0 | 네트워크를 끊고 질문을 보낸다 | 패널 답변 줄 왼쪽에 빨간 띠 + `답변을 못 받았어요` + 사유 + `다시 시도`. 카드 없음 |

## 2. 자동 테스트가 못 잡는 것 (반드시 실기기)

| ID | 우선순위 | 조건·동작 | 기대 결과 |
|---|---|---|---|
| TRV-101 | P0 | 캐러셀을 옆으로 넘긴다 | 손을 뗀 카드에 스냅하고 **지도가 그 핀으로 팬**한다. 그 핀만 라벨 달린 빨간 물방울, 나머지는 파랑 |
| TRV-102 | P0 | 지도의 다른 핀을 탭한다 | 상세로 가지 않고 **캐러셀이 그 장까지 스크롤**하며 번호 배지·placeholder·문맥 칩이 함께 바뀐다 |
| TRV-103 | P0 | 결과가 있는 상태에서 패널 아래를 본다 | 문맥 칩이 탭 바에 가리지 않는다 — 칩과 탭 바 사이에 입력 줄이 통째로 들어간다 |
| TRV-104 | P0 | **위치 권한 미설정** 상태에서 결과를 받는다 | 프라이머가 패널과 입력 줄 **사이**에 들어가 독이 47px 자라고 패널이 그만큼 올라간다. 여전히 안 가린다 |
| TRV-105 | P0 | 사진을 첨부한 채 결과를 본다 | 첨부 배너(73px)가 들어와 패널이 73px 올라간다. 프라이머는 사라진다 |
| TRV-106 | P0 | 입력 필드를 탭해 키보드를 올린다 | 키보드가 입력 필드를 가리지 않는다. 긴 문장을 쳐도 필드가 화면 밖으로 밀리지 않는다 |
| TRV-107 | P0 | 패널 좌우 바깥 여백, 패널과 입력 줄 사이, 칩 행 오른쪽 빈 자리에서 팬을 시작한다 | 세 자리 모두 **지도가 움직인다** — 투명한 층이 제스처를 먹지 않는다 |
| TRV-114 | P0 | 밝은 지도 위에서 패널 글씨를 읽는다 | 지도의 흰 도로·라벨이 패널을 **비추지 않는다**. 패널이 불투명하고 **iOS 에서도** 아래에 그림자가 깔린다(클리핑 뷰가 그림자를 먹지 않는다) |
| TRV-115 | P0 | 패널이 없는 빈 화면과 있는 화면을 오간다 | 패널이 지도 아래에서 올라오고, `새 대화`를 누르면 통째로 사라진다. 남는 잔상·빈 상자가 없다 |
| TRV-108 | P0 | 카드 아무 데나 한 번 탭한다 | 곧바로 상세로 간다. 두 번 탭을 기다리는 지연이 없다 |
| TRV-109 | P1 | 성질 칩(`한산`·`유사도 87%`)을 탭한다 | 서버 문구 그대로 토스트가 뜬다(`혼잡도 8/3 예측 기준` 등). 거리 태그에는 칩 자체가 없다 |
| TRV-110 | P0 | VoiceOver·TalkBack으로 카드를 훑는다 | 한 번 활성화로 상세가 열리고, 저장·상세보기·성질 칩이 각각 이름을 갖는다 |
| TRV-111 | P0 | 문맥 칩 셋 + refine 이 넘치는 상태에서 칩 행을 왼쪽으로 끝까지 민다 | `사진` 칩이 **왼쪽에 그대로 남는다** — 나머지 칩만 그 오른쪽에서 스크롤한다. 긴 스팟 이름(`한국민속촌 근처 볼거리`)에서도 칩이 두 줄로 접히지 않는다 |
| TRV-112 | P0 | 질문을 보낸 뒤 응답이 오기 전에 **스켈레톤 카드 위에서** 팬을 시작한다 | 지도가 따라 움직인다 — 스켈레톤은 제스처를 먹지 않는다 |
| TRV-113 | P0 | 질의 중 → 결과 도착을 지켜본다 | 패널 높이가 그대로다. 스켈레톤이 카드로 바뀔 뿐 지도 여백이 위아래로 튀지 않는다(0곳 답은 예외 — 카드가 없으므로 그만큼 내려앉는다) |

| ID | 우선순위 | 조건·동작 | 기대 결과 |

| TRV-206 | P0 | 약관 화면의 동의 내역을 본다 | 사진 분석 동의 항목이 없다 — 위치 동의와 약관 버전만 남는다 |
| TRV-207 | P0 | 계정 화면에서 탈퇴 확인을 연다 | 체크리스트가 `저장한 모든 스크랩` · `계정 정보와 로그인 연결` 둘뿐이고, 개인정보처리방침이 선언하지 않는 항목을 약속하지 않는다 |

## 4. 질의·사진·저장 회귀

| ID | 우선순위 | 조건·동작 | 기대 결과 |
|---|---|---|---|
| TRV-301 | P0 | 응답을 기다리는 동안 전송을 반복한다 | 두 번째 요청이 나가지 않고 턴이 하나만 생긴다 |
| TRV-302 | P0 | 실패한 턴에서 `다시 시도`를 누른다 | 같은 payload를 다시 보내고 턴이 늘어나지 않는다. 사진 턴이면 같은 사진이 다시 실린다 |
| TRV-303 | P0 | 첫 답 뒤 `거기 근처 카페는?`을 입력한다 | 직전 답의 `intent` 와 보고 있는 카드의 `contentId` 가 함께 나간다 |
| TRV-304 | P0 | `{제목} 근처 맛집` 칩을 누른다 | 보고 있는 카드의 `contentId + action` 만 나가고 **새 턴의 질문 줄이 칩 글씨와 글자 그대로 같다** |
| TRV-310 | P0 | 빈 화면에서 `근처 볼거리`를 누른다(좌표 있음) | 앵커가 아니라 `intent{nearMe}` 로 나간다 — 3km 반경에 갇히지 않는다 |
| TRV-305 | P0 | 카메라 권한을 거절하거나 앨범 선택을 실패시킨다 | 각각 다른 토스트가 뜨고 작성 중인 문장이 유지되며 요청은 발생하지 않는다 |
| TRV-306 | P0 | 사진만 첨부해 전송한다 | 서버 질문 필드는 비고 답변 바 질문 줄은 `이 사진 같은 분위기의 여행지` |
| TRV-307 | P0 | 로그인·비로그인 상태에서 카드 하트를 누른다 | 서버 성공 뒤에만 상태가 확정되고 토스트가 뜬다. 비로그인은 로그인 유도 후 잘못된 하트 상태가 남지 않는다 |
| TRV-308 | P0 | 사진 요청 뒤 서버 저장소와 구조화 로그를 점검한다 | 원본 bytes, 로컬 URI, 파일명이 저장·로그에 남지 않는다 |
| TRV-309 | P1 | 20회 이상 질문과 캐러셀·지도 왕복을 반복한다 | 입력 지연, WebView 누적, 메모리 경고, 앱 종료가 없다 |

## 검증

```bash
cd mobile
npm run lint && npm run typecheck && npm run format:check && npm test
```

여행 탭만 좁혀 돌릴 때:

```bash
cd mobile
npm test -- --runInBand src/__tests__/travel-screen.test.tsx src/features/travel
```

사진 업로드 계약이나 답변 문장을 건드렸다면 백엔드 경계 테스트도 실행한다.

```bash
cd backend
NO_COLOR=1 POSTGRES_DB=pictrip_test uv run pytest tests/test_agent_ask.py tests/test_agent_anchor.py
```

## 출시 판정

- P0 항목은 두 OS에서 모두 통과해야 한다.
- 자동화 명령은 모두 종료 코드 0이어야 한다.
- 사진 비영속성, 카드가 탭 바에 가림, 캐러셀↔지도 불일치, 상세 진입 불가, 저장
  상태 불일치는 건수와 관계없이 출시를 차단한다.
- 실제 권한 다이얼로그, 키보드, 스크린 리더, 저사양 성능은 단말에서 최종 판정한다.

## 자주 나는 문제

| 증상 | 먼저 확인할 것 |
|---|---|
| 패널이 탭 바에 가림 | `dockBasePx({primer, attached, chips})` 가 결과 중 `chips: false` 를 받는지, 패널이 `bottom = dockBase` 를 쓰는지 |
| 지도 여백이 카드와 안 맞음 | `mapFitPadding` 의 `bottom` 이 `coveredPx`(독 + 패널 + 캐러셀 135)를 받는지 |
| 패널 옆에서 지도가 안 움직임 | `ResultPanel` 과 `ChipRow` 의 `pointerEvents="box-none"` 이 살아 있는지 |
| 패널 뒤로 지도가 비침 | `panelStyles.root.backgroundColor` 가 `colors.inset`(불투명)인지 — `glassFill` 은 밝은 지도에서 뭉갠다 |
| iOS 에서만 패널 그림자가 없음 | `overflow: hidden` 이 `shadows.card` 와 같은 뷰에 있는지 — 바깥은 그림자, 안쪽은 클리핑으로 갈라야 한다 |
| 켠 직후 근처 칩이 위치를 켜라고 함 | `demandCoords` 가 `phase === "checking"` 을 먼저 거르는지, `ask()` 가 요청 중에 `phase` 를 `checking` 으로 두는지 |
| 칩이 빈 화면에서 사라짐 | 초기 칩은 좌표와 무관하게 고정이다. `dockChips()` 에 분기를 되살리지 않았는지 |
| 칩이 두 줄로 접힘 | `chipStyles.band.alignItems` 가 `flex-start`, `track.flexGrow` 가 0 인지 |
| 넘겨도 지도가 안 따라옴 | `onMomentumScrollEnd` 가 인덱스를 계산하는지, `focused` 좌표가 `null` 이 아닌지 |
| 핀을 눌러도 캐러셀이 안 감 | `scrollToIndex` 를 넘긴 뒤 다음 포커스 변경에서 `null` 로 되돌리는지 |
| 성질 칩 문구가 이상함 | 클라이언트는 서버 `tag` 를 그대로 쓴다 — 서버 응답을 먼저 본다 |
| 답변이 통째로 한 줄 | 서버 문장에 문장 부호가 없으면 보충이 생기지 않는다(`answer-split`) |
| 씨앗 카드 위로 옛 답이 남음 | `seeded` 일 때 `clearTurns()` 가 도는지, 전송 시 `clearSeed()` 하는지 |
| 저장 토스트가 실패 뒤에도 뜸 | `toggle()` 의 `true/false/null` 결과를 mutation 완료 뒤 처리하는지 |
