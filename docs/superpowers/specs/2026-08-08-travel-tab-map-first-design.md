# 여행 탭 개편 — 지도 우선 + 좌우 캐러셀

> 설계 확정본. 구현 후에는 `docs/reference/travel-tab.md` 를 이 내용으로 다시 쓰고
> 이 문서는 역할을 마친다. 프로토타입(`travel-tab-v2.html`)은 스크래치패드에만 두고
> 리포에 남기지 않는다.

## 왜 바꾸나

지금 여행 탭은 **지도 위에 3단 글래스 시트**가 덮인 구조다. 결과를 읽으려면 시트를
올리고, 위치를 보려면 내린다. 대화가 세로로 쌓여 3턴이면 스크롤이 길고, 과거 턴의
결과는 지도에 반영되지도 않는다(`lastAnswered` 하나만 그린다). 시트를 올린 상태가
기본이라 **지도가 배경으로만 존재한다.**

바꾼 뒤에는 지도가 상시 주인공이고, 결과는 지도 위를 좌우로 흐르는 카드다.

## 구조

화면은 3층으로 고정된다. 시트도, 스냅도, 드래그도 없다.

| 층 | 내용 | 상시 여부 |
|---|---|---|
| 답변 바 | 질문 라벨 + 에이전트 답변 | 턴이 있을 때만 |
| 캐러셀 | 결과 카드 가로 스크롤 + 진행 바 | 결과가 있을 때만 |
| 독 | 칩 행 + 입력 필드 | **항상** |

**대화 이력은 두지 않는다.** 화면에 존재하는 것은 마지막 턴 하나뿐이고, 새 질문이
오면 답변 바와 캐러셀이 통째로 교체된다. 되돌아가는 빈도가 낮고, `context` 가 이미
직전 턴을 자동으로 실어 보내므로 "이어 묻기"는 이력 없이 동작한다.

### 세로 예산 (390×844, bottom inset 34)

| 요소 | px |
|---|---|
| 탭바 | 83 |
| 필드 | 46 + 여백 12 |
| 칩 행 | 33 + 여백 9 |
| 진행 바 | 3 + 여백 11 |
| 캐러셀 | 112 + 여백 9 |
| **하단 합계** | **318** |

지도는 세로 62% 를 유지한다. 세로 사진 카드(높이 248)를 골랐다면 136px 를 더
먹었고, 그러면 "8곳이 제주 동쪽에 몰려 있다"가 화면에서 사라진다.

## 답변 바

```
┌────────────────────────────────┐
│ 제주에서 한적한 곳            ✕ │  11 ter — 질문은 라벨로 강등
│ 혼잡도 하위 20% 안쪽으로만      │  14.5/700 ink — 답변이 헤드라인
│ 골랐어요.                    ⌄ │  2줄 clamp, ⌄ 탭 = 전문
└────────────────────────────────┘
```

- 위치 `top: 66`, 좌우 14, radius 16, `glassFill` + `glassBorder`, blur 22.
- 접힘 = 2줄 clamp. 펼치면 헤드라인은 흰 볼드로 남고 **보충 문장만** `sec` 600 으로 붙는다.
- `✕` = 새 대화. 지금 우상단에 떠 있는 컨트롤을 여기로 흡수한다.
- 사진 턴이면 좌측에 40px 내 사진 썸네일. "이 사진으로 찾은 결과"가 계속 읽힌다.
- 진행 중에는 답변 자리에 스피너 + 단계 한 줄(`질문에서 조건 읽는 중`).
- 실패면 좌측 3px `accent` 라인 + 헤드라인이 `accentText`, 우하단에 `다시 시도`.

### 위계를 뒤집는 이유

지금은 사용자가 방금 친 말이 가장 강한 활자(13.5/700 흰색)를 먹고, 앱이 하는 말은
회색 12.5 로 밀려 한 줄에서 잘린다. **에코가 주인공이고 답이 각주다.** 질문은 방금
자기가 친 것이라 확인만 되면 되므로 라벨로 충분하다.

## 카드

```
┌──────────────────────────┐
│┌────┐ ① 성산일출봉     ♡ │  296×112, radius 18, 썸네일 92
││ 92 │  서귀포시 · 2.4km   │
││    │  ⚇한적함  상세보기› │
│└────┘                     │
└──────────────────────────┘
```

| 요소 | 값 |
|---|---|
| 카드 | 296×112, radius 18, `glassFill` + `glassBorder`, blur 22, 카드 간 gap 10 |
| 썸네일 | 92×92, radius 12, `cover` |
| 번호 배지 | 20px **원형**, 흰 배경 + `#0C0E11` 숫자 — **지도 핀과 같은 모양** |
| 제목 | 15/700 `ink` 1줄 |
| 메타 | 12.5 `sec` — `지역 · 거리(볼드 ink)` |
| 성질 칩 | 22px, `fill` + 1px `line`, 아이콘 + 11.5/700 `sec` |
| 상세보기 | 24px, **테두리만**(투명 배경) + 셰브런, 11.5/700 `sec`, 우측 정렬 |

다음 카드가 56px(≈15%) 걸쳐 보인다 — 인디케이터 없이 "더 있다"가 읽힌다.

### 카드에 액션 버튼을 두지 않는다

버튼 두 개를 나란히 두니 카드가 **다이얼로그 푸터**로 읽혔다. 지도 앱의 카드에는
버튼이 없다 — 카드 자체가 버튼이고 나머지는 아이콘이다. 장소가 가진 행동 셋을
서로 다른 종류의 표적에 나눈다.

| 행동 | 표적 |
|---|---|
| 상세 | `상세보기 ›` (명시) + 카드 본문 탭 (관습적 보조 경로) |
| 저장 | `♡` |
| 근처 묻기 | **칩 행** (카드 밖) |

`상세보기`는 성질 칩과 **같은 줄** 오른쪽 끝이다. 새 줄을 만들지 않아 카드가 112 로
유지된다. 둘 다 알약이지만 성질 칩은 **채워** 있고 상세보기는 **테두리만** 있어
정보와 행동이 갈린다.

`한 번 탭 = 앵커 / 두 번 탭 = 상세` 는 폐기한다. 발견 불가였던 원인은 카드 탭 자체가
아니라 **비관습적 매핑**이었다. `useCardTap`(260ms 판정)과 VoiceOver 커스텀 액션
우회도 함께 사라진다.

## 진행 바가 `추천 N곳` 을 대체한다

캐러셀 아래 3px 바. 8곳 중 3번째면 37.5% 가 찬다(최소 폭 14px). 텍스트 0개이고
개수는 답변 바가 문장으로 말한다. 목록 제목 `추천 N곳` 은 없앤다.

## 성질 칩 — `직선거리 기준` 각주를 없앤다

거리는 **잰 값**이라 배지가 아니라 사실이므로 지역 줄로 내린다(`서귀포시 · 2.4km`).
칩에는 **예측한 성질 하나만** 남으므로 칩 자체가 "이건 예측값"이라고 말한다.

**라벨은 서버 `tag` 를 그대로 통과시킨다.** 클라이언트는 아이콘과 툴팁만 고른다.

| 아이콘 | 서버가 주는 `tag` | 탭 툴팁 (2.6초) |
|---|---|---|
| users | `한산` · `보통` · `붐빔` · `하위 N%` | `혼잡도 8/3 예측 기준` |
| image | `유사도 N%` | `사진 유사도 기준` |
| calendar | `D-N` | `축제 기간 기준` |
| tag | 그 외 | (없음 — 탭해도 반응하지 않는다) |

거리 태그(`N.Nkm` · `Nm`)는 칩을 만들지 않는다 — 지역 줄이 이미 말한다.

**초기 목업의 `한적함`·`분위기 비슷` 은 폐기했다.** 클라이언트가 낱말을 지어내면
`유사도 87%` 라는 실측값을 버리게 되고, 무엇보다 CLIP 은 벡터를 줄 뿐 벡터에 이름을
주지 않으므로 `분위기` 라는 속성명 자체가 지어낸 것이다. 툴팁 문구가 접근성 라벨을 겸한다.

## 독 — 칩 행이 보고 있는 카드를 따라간다

```
접힘  [▣사진] [◎ 성산일출봉 근처] [사람 적은 곳만] ▸
       ↓ 탭
펼침  [◎ 성산일출봉 ✕] [맛집] [카페] [볼거리] ▸
```

- **`사진` 칩은 좌측 고정**이고 나머지만 가로 스크롤한다. 앵커·refine 상태에서도 안
  밀려나가므로 사진이 모든 상태에서 닿는다. 강조는 **아이콘 틴트로만** 한다 —
  테두리까지 accent 로 하면 옆의 문맥 칩과 싸운다.
- 촬영은 필드 안 카메라 아이콘 하나. 앨범이 압도적으로 잦아 칩을 앨범에 준다.
- 펼침 상태에서 **문맥 칩만 accent** 로 남고 술어는 중립이다 —
  `성산일출봉 → 맛집` 으로 읽힌다. 술어까지 accent 로 채우면 4개가 서로 싸운다.
- 좌표가 없으면 근처 칩 대신 전국 칩(`지금 축제`·`사람 적은 바닷가`·`비 와도 갈 만한
  실내`). 권한이 `undetermined` 일 때만 칩 행 위에 프라이머 한 줄.
- 사진 첨부 시 **첨부 배너가 칩 행 자리를 대체**한다. 둘이 동시에 뜨지 않아 세로 한
  줄을 아낀다.

### 앵커 모드를 없앤다

**캐러셀에서 보고 있는 카드가 곧 기준점이다.** 잡을 것도 풀 것도 없다. 기준점이
무엇인지는 세 곳이 동시에 말한다 — 화면 정중앙의 카드, `accent` 로 켜진 핀, 그리고
placeholder(`성산일출봉에 대해 물어보기`).

사라지는 것: 앵커 잡기/해제 동작 · 필드 안 앵커 토큰 · 카드 선택 톤 · `기준 해제`
버튼 · `anchor-store` 의 토글 경로.

**알려진 트레이드오프.** 넘기다 멈춘 카드가 기준이 되므로 "내가 골랐다"는 확정
동작이 없다. 손을 뗀 자리가 곧 보고 있는 곳이라 실사용에서는 문제되지 않는다고
본다. 문제가 되면 문맥 칩을 **탭하는 순간**에만 기준을 확정하고 그전까지는
placeholder 를 중립으로 두는 방식으로 되돌릴 수 있다.

## 지도 연동

- 캐러셀을 넘기면 그 핀이 `accent` 로 바뀌고 지도가 그리로 팬한다.
- 핀을 탭하면 캐러셀이 그 장으로 스크롤한다. **상세로 보내지 않는다** — 지도에서
  바로 상세로 튀면 "8곳이 어디 있나"를 보려고 지도에 있던 맥락을 잃는다.
- 새 결과가 오면 전체 `fit` + 1번 카드. `fit` 의 아래 패딩은 캐러셀 높이 고정이므로
  더 이상 시트 높이에 따라 재계산하지 않는다.
- 결과 핀은 `info` 파랑, 보고 있는 카드의 핀은 라벨 달린 큰 `accent` 물방울.
  카테고리 글리프·한반도 클램프·다크 반전 필터는 그대로 둔다.

| # | 상태 | 답변 바 | 캐러셀 | 칩 행 |
|---|---|---|---|---|
| 1 | 빈 상태 | 없음 | 없음 | 사진 · 근처 맛집 · 근처 볼거리 · 근처 카페 |
| 2 | 좌표 없음 | 없음 | 없음 | 프라이머 + 전국 칩 |
| 3 | 사진 첨부 | 없음 | 없음 | **첨부 배너로 대체** |
| 4 | 질의 중 | 질문 + 단계 스피너 | 스켈레톤 | 직전 칩 유지, 전송 비활성 |
| 5 | 결과 | 헤드라인 2줄 clamp | 카드 N장 | 사진 · 문맥 칩 · refine |

| 7 | 문맥 칩 펼침 | 그대로 | 그대로 | 문맥 칩 + 술어 |

## 백엔드 변경 — 답변 문장

**이건 프론트만의 일이 아니다.** `answer` 는 `app/modules/agent/services/ask.py` 의
**결정적 템플릿 코드**가 만든다(LLM 아님). `AnswerSegment(text=f"{len(top)}곳",
emphasis=True)` + `" 추렸어요"` 패턴이 `ask.py` 에 약 8곳, `detail.py` 에 추가로 있다.

### 규칙: 구체적 사실이 헤드라인, 개수·조건은 보충

문장을 새로 짓는 게 아니라 **이미 만들고 있는 두 문장의 순서를 뒤집는다.**

```
지금  "혼잡도 조건으로 8곳 추렸어요. 모두 이 조건 안에서 혼잡도 하위 20% 안쪽이에요."
바꿈  헤드라인  혼잡도 하위 20% 안쪽으로만 골랐어요.
      보충      제주 동쪽으로 8곳이에요.
```

| 턴 | 헤드라인 (emphasis) | 보충 |
|---|---|---|
| 혼잡도 조건 | 혼잡도 **하위 20%** 안쪽으로만 골랐어요. | 제주 동쪽으로 8곳이에요. |
| 거리 조건 | 가장 가까운 곳이 **2.4km** 예요. | 조건에 맞는 8곳이에요. |
| 사진 | **협재해수욕장** 이 가장 비슷해요. | 사진과 닮은 8곳이에요. |
| 지역 확장 | **경남까지** 넓혔어요. | 통영 기준 6곳이에요. |
| 0곳 | **울릉도 · 실내** 조건으로는 없어요. | 지역을 넓히면 나올 수 있어요. |

`AnswerPart` 스키마는 그대로다. 모바일이 **첫 문장을 헤드라인으로, 나머지를 보충으로**
그리므로 서버는 문장 경계만 지금처럼 유지하면 된다.

### emphasis 대상을 바꾼다

숫자(`8곳`)가 아니라 **장소명·측정값·조건**에 건다. 숫자를 `accentText` 볼드로 칠하면
문장이 통계표로 읽힌다.

### 안 하는 것 (배관이 없다)

`성산·우도는 오늘 붐벼서 뺐어요` 류는 **지금 데이터로 못 만든다.** `_answer()` 는
추린 `top` 만 받고 탈락 후보와 사유는 넘어오지 않는다. 하려면 retrieve 단계가
탈락 사유를 함께 실어야 하므로 이번 범위에서 뺀다.

`무엇을 보고 닮았다 했는지` 는 **앞으로도 적지 않는다.** CLIP 은 벡터를 줄 뿐 벡터에
이름을 주지 않는다(기존 규칙 유지).
