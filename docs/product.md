# 제품 (Product)

> 갱신: 2026-07-17 · 화면의 SSOT는 구현된 앱(`mobile/src`) — 이 문서는 현행
> 제품이 "무엇인지"를 기록한다. 수치·동작이 갈리면 코드가 맞다.

## 컨셉

해외 여행 사진 피드를 구경하다 마음에 드는 장면을 만나면, 스와이프로 **닮은
분위기의 국내 관광지 3곳**을 보여준다. 텍스트 검색·사진 업로드 없이 "발견 →
매칭" 한 동작이 핵심 루프다. 매칭은 CLIP 이미지 임베딩 코사인 거리(LLM 미사용),
데이터는 KTO TourAPI + Wikidata/Commons.

## 화면 구조 (4탭 + 스택)

```
BootGate(스플래시) → 온보딩(최초 1회, 3스텝) → 탭 셸
├── 홈      해외 게시물 피드 + 상단 채널 타일
├── 탐색     해외 게시물 그리드 (다크, big/side 혼합 3열)
├── 지도     내 주변 (KakaoWebMap + 바텀시트)
└── 마이     프로필 · 스크랩 레일 · 설정
스택: 스팟 상세(/spots/[contentId]) · 스토리 뷰어(/channels) ·
      로그인(/auth/login·email) · 스크랩 전체(/saved) · 약관(/legal/*)
```

전 화면 **게스트 우선** — 로그인이 필요한 유일한 행동은 저장(스크랩)이며,
그 순간 루트 `AuthPromptSheet`가 뜨고 로그인 성공 시 보류된 저장이 재개된다.

## 핵심 플로우

### 홈 피드 → 매칭
- `GET /feed`(seed+커서, 6개 단위 무한스크롤). 각 게시물은 **가로 캐러셀**:
  슬라이드 0 = 해외 hero(이름·국가·설명·ⓘ 저작자/라이선스 시트), 슬라이드 1~3 =
  국내 매칭 카드(`GET /overseas/{id}/matches`, 스와이프 시작 시 지연 로드,
  스켈레톤 3장 → 카드).
- 매칭 카드 = 제목·지역·overview 첫 문장·저장 버튼. 탭 → 스팟 상세(프리페치 후).
  유사도 수치는 UI에 노출하지 않는다(순번 1/2/3만).
- 당겨서 새로고침 = 새 seed(피드 재셔플) + 매칭 무효화.

### 채널 스토리
- 홈 상단 타일 6종: `around`(내 주변) · `hot` · `hidden` · `festa` · `pets` ·
  `snap`. 본 채널은 KST 일 단위로 dim 처리.
- 탭 → 인스타형 스토리 뷰어: 좌/우 탭 = 카드 이동, 좌우 스와이프 = 채널 전환,
  아래 스와이프 = 닫기. `around`만 위치 권한 필요(미허용 시 프라이머).
  카드 버튼 → 스팟 상세.

### 탐색
- `GET /explore`(피드와 동일한 해외 게시물 소스, 30개 단위). 타일 탭 →
  모달로 홈과 동일한 캐러셀(hero+매칭)을 띄운다.

### 지도 (내 주변)
- 진입 시 위치 권한 프라이머(거부 시 서울 중심 degraded). `GET /map/nearby`
  (뷰포트 bbox + 카테고리 단일선택: 전체·관광지·음식점·카페·레저·쇼핑).
- 패닝이 마지막 검색 중심에서 반경의 30% 이상 벗어나면 **"이 지역에서 검색"**
  pill이 떠서 탭해야만 재조회한다(자동 재조회 없음 — 결과 흔들림 방지).
- 바텀시트 3스냅(peek/half/full)에 카드 최대 30개(거리 표기). 핀/카드 탭 →
  상세 시트가 상승. 헤더 지역 라벨 = 역지오코딩(`GET /map/region`), 탭 →
  지역 피커(시도→시군구, centroid로 재센터).

### 스팟 상세
- 풀스크린 라우트와 지도 상승 시트가 같은 컴포넌트를 공유. 카드가 넘긴 seed로
  hero를 즉시 페인트하고 본문은 스켈레톤.
- 섹션: hero(글래스 nav·제목·카테고리/지역 서브라인·갤러리 스트립 3+N) →
  소개(`overview` verbatim, 5줄 클램프) → 위치(카카오 미니맵·네이버/카카오
  링크·주소 복사·시간·전화·홈페이지) → 방문 예정(공유/스크랩) → 주변 추천
  레일(반경 3km, 12개, 자기 제외).

### 인증
- OAuth 3종(kakao·google·apple) + 이메일. Apple은 iOS 네이티브 전용,
  Kakao는 https 바운스(`pictrip.org/oauthredirect` → `pictrip://`),
  Google은 reversed-client-id 스킴.
- 로그인 성공 시 동의 스냅샷을 베스트에포트로 기록(약관 버전
  `constants/legal.ts`). `/consent` 관리 화면은 구현돼 있으나 현재 진입
  링크가 없다(미노출).

## 이미지 표시 규칙 (클라이언트)

`RemoteImage` 단일 컴포넌트가 담당:
- KTO 이미지는 하단 ~12% 워터마크 밴드를 프레임 밖으로 밀어내는 **클라이언트
  표시 프레이밍**(`cropBanner` — CSS 클리핑, 파일 바이트 무변형이라 공공누리
  Type 구분과 무관). 파일을 실제로 변형하는 서버측 변환(`/t1` 리사이즈)은
  `Type1`에만 발급되고 `Type3`는 원본 pass-through — 발급 로직은
  `backend/.../feed/services/display.py`. 출처표시는 홈 푸터 "데이터 출처" +
  `pictrip.org/legal/data-sources`로 이행.
- Commons·KTO URL은 `img.pictrip.org` 프록시로 재작성(엣지 캐시).
- 폴백 체인: 원본(`_image1_1`) 실패 → 미드사이즈(`_image2_1`) / 프록시 실패 →
  직접 Wikimedia(전용 UA) → 백오프 재시도 2회 → 회색 박스.
- blur-up: 미드사이즈를 블러 프리뷰로 먼저 그리고 본 이미지를 페이드인.
  캐시는 expo-image memory-disk.

## 릴리스

- 스킴 `pictrip://`, 유니버설 링크 `https://pictrip.org/spots/…`,
  번들 `com.jeongeup.pictrip`, 배포는 TestFlight.
- JS 변경 = dev 머지 → EAS OTA 자동. 네이티브 변경 = main에서 `v*` 태그 →
  TestFlight 빌드 (fingerprint 가드가 OTA 오배포를 차단).
