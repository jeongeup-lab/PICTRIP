# 0005. KTO 이미지 정책 — 공공누리 경계로 재정의

- 상태: 채택 (구 "URL-only" 정책 대체)
- 날짜: 2026-07-16
- 관련: `workers/img-proxy/`, `app/modules/feed/services/display.py`, [api](../reference/api.md)

## 맥락
구 정책은 "KTO 이미지 다운로드·재호스팅 금지 = 실격"으로 보수 가정했다.
2026-07-16 공모전 운영사무국 확인 + 2026 설명회 자료(46p)·OT자료(24p)·활용매뉴얼
v4.4 원문 전수 재분석 결과, 이미지 다운로드 금지 조항은 존재하지 않았다 —
"다운로드 금지"의 실체는 **콘텐츠랩 파일데이터를 데이터 소스로 쓰면 OpenAPI
활용으로 불인정**한다는 규정(이미지와 무관)이었다.

## 결정
**경계는 공공누리 `cpyrhtDivCd`다.** `Type1`(출처표시)은 리사이즈·포맷 변환 가능,
`Type3`(변경금지)는 원본 무변형 pass-through만. 출처(한국관광공사) 표기를
유지하고, 데이터 소스는 OpenAPI 호출이어야 한다. 프록시/CDN 캐싱은 허용.
서버측 변환(`img.pictrip.org/t1/…` HMAC 서명 리사이즈)은 Type1에만 발급하며,
발급 SSOT는 `feed/services/display.py`다. 클라이언트 CSS 프레이밍(워터마크 밴드
클리핑)은 파일 바이트를 건드리지 않으므로 Type 구분과 무관하다.

## 고려한 대안
- **URL-only 보수 유지** — 원본 저화질·콜드 로딩을 감수해야 하고, 근거 조항이
  실재하지 않음이 확인됨. 기각.

## 결과
- 매칭·채널 이미지는 t1 변환(폭 1620 무손실 원칙) + 일일 엣지 워밍.
- 사무국 답변 원문은 미보관(사용자 보고) — 확보 시 이 ADR에 첨부한다.
- 사용자 업로드 이미지 미영속·`overview` verbatim 원칙은 그대로다.
