# 0016. 앱 안의 지도 화면을 걷어내고, 지도는 라이트로 돌린다

- 상태: 일부 대체 — 남는 파일 목록의 `list-padding` 은
  [0017](0017-travel-tab-drops-the-sheet-for-a-map-carousel.md) 이 시트와 함께
  지웠다. 지도 화면 제거와 라이트 타일 복귀는 그대로다
- 날짜: 2026-08-08
- 관련: [0015 여행 탭은 지도 하나 위에서 돈다](0015-travel-and-profile-go-dark-on-one-map.md),
  [0017 시트를 버리고 지도 위 캐러셀로](0017-travel-tab-drops-the-sheet-for-a-map-carousel.md),
  [profile-tab](../reference/profile-tab.md),
  [product](../explanation/product.md)

## 맥락

0015 는 두 개의 탈출구를 남겨 뒀다 — "카카오 다크는 실기기 검증 전이다. 어색하면
`dark` 를 끄면 된다", 그리고 "`/map` 은 남는다. 카테고리 칩·이 지역 검색·지역
선택기를 여행 탭이 아직 갖지 않았다".

QA 에서 둘 다 걸렸다. 반전 타일은 실기기에서 지명 라벨이 읽히지 않았다. `/map`
은 스팟 상세의 `주변 둘러보기` 배지 **한 곳**에서만 닿는 화면이었는데, 거기서
기대하는 행동(길찾기·주변 가게 확인)은 결국 카카오 지도 앱으로 나가는 것이었다.

## 결정

**`/map` 을 지운다.** 상세의 미니맵은 비대화형 프리뷰로 남기고, 탭하면 아래
`카카오 지도` 버튼과 같은 딥링크로 나간다. 진입점이 하나뿐이었으므로 화면과 그
전용 코드가 통째로 죽는다 — 시트·칩·지역 선택기·`map-store`·뷰포트 계산 등
21개 파일. `SpotDetailSheet` 도 `/map` 전용이라 함께 내린다.

배지 문구는 남기지 않는다. 프리뷰 바로 아래에 `네이버 지도`·`카카오 지도`
버튼이 이미 있어 배지는 같은 말을 두 번 하는 것이었다.

**카카오 다크 반전을 되돌린다.** `dark` 옵션과 `DARK_FILTER` 를 없애고 기본
basemap 을 쓴다. 앱 크롬은 다크로 두되 지도만 라이트다 — 반전 타일은 색을
뒤집을 뿐 대비를 만들지 못한다. 핀·라벨은 원래 색이 밝은 지도 위에서 성립하므로
따로 손대지 않는다.

**스크랩은 앨범 한 겹으로 고정한다.** 정렬 칩(`최근 저장 순`·`가까운 순`·
`지역별`)과 목록/그리드 토글을 없애고 2열 앨범만 남긴다. `가까운 순` 은 위치
권한과 실패 문구까지 끌고 들어왔는데, 스크랩은 "다시 보려고 저장한 사진 더미"로
쓰인다. 사진이 곧 식별자라면 정렬 축은 값을 못 한다.

**약속하지 않은 기능을 화면에서 뺀다.** 알림 스위치 3종과 스크랩 CSV 내보내기를
삭제한다. 발송 경로가 없는 스위치는 켤 수 있다는 거짓 약속이고, 마이 탭의
`알림·권한 설정` 은 없는 기능을 메뉴 이름에 박아 뒀다 → `권한 설정`.

**앱 안의 출처 문구를 전부 내린다.** 마이·설정 각주, 계정 탈퇴 힌트, 약관 탭의
`데이터 출처` InfoBox 와 문서 행까지 없앤다. 공공누리 출처표시 의무는
`pictrip.org/legal/data-sources` 가 전담한다 — 웹 문서는 그대로 살아 있다.

**표기는 `PICTRIP` 대문자로 통일한다.** 홈 워드마크만 대문자였고 스플래시·로그인
카드·공유 문구는 `PicTrip` 이었다. 프로토콜 값은 건드리지 않는다 —
`X-PicTrip-Detail-Mode` 헤더, KTO `MobileApp` 파라미터, Commons User-Agent.

## 결과

- `app.json` 의 `name` 이 바뀌어 `runtimeVersion.policy: fingerprint` 가 바뀐다.
  이 PR 은 OTA 로 나가지 않는다 — `v*` 태그 네이티브 빌드가 필요하다.
- 앱 안에 관광 정보 출처 표기가 남지 않는다. 심사에서 앱 내 표기를 요구하면
  약관 탭 문서 행을 되살리는 것이 가장 싼 복구다.
- 카테고리 칩·이 지역 검색·지역 선택기는 사라진다. 여행 탭이 대화로 같은 일을
  하므로 되살릴 계획은 없다.
- `mobile/src/features/map/` 에는 `KakaoWebMap`·`PermissionPrimer`·`geo`·
  `kakao-map-html`·`request-location` 만 남는다 — 전부 여행 탭·채널·상세가 쓴다.
