# 제품 개요

> 이 문서는 PicTrip이 무엇인지 — 핵심 루프·화면 구조·주요 플로우를 설명한다.

## 맥락

해외 여행 사진 피드를 구경하다 마음에 드는 장면을 만나면, 스와이프로 **닮은
분위기의 국내 관광지 3곳**을 보여준다. 텍스트 검색·사진 업로드 없이 "발견 →
매칭" 한 동작이 핵심 루프다(→ [ADR-0004](../adr/0004-s13-overseas-feed.md)).
2026 관광데이터 활용공모전 출품작, 1차 마감 2026-09-21.

화면의 SSOT는 구현된 앱(`mobile/src`)이다(→
[ADR-0006](../adr/0006-design-ssot-is-the-app.md)) — 이 문서와 코드가 갈리면
코드가 맞다.

## 화면 구조

```
BootGate(스플래시) → 온보딩(최초 1회) → 탭 셸
├── 홈      해외 게시물 피드 + 상단 채널 타일
├── 탐색     해외 게시물 그리드 (다크, big/side 혼합)
├── 여행     대화형 추천 (풀블리드 KakaoWebMap + 결과 패널·독)
└── 마이     프로필 · 스크랩 레일 · 설정
스택: 스팟 상세 · 스토리 뷰어 · 로그인 · 스크랩 앨범 · 약관
```

전 화면 **게스트 우선** — 로그인이 필요한 유일한 행동은 저장(스크랩)이고,
그 순간 루트 `AuthPromptSheet`가 떠서 로그인 성공 시 보류된 저장이 재개된다.

## 핵심 플로우

- **홈 피드 → 매칭** — 게시물마다 가로 캐러셀: 슬라이드 0 = 해외 hero(ⓘ로
  저작자/라이선스 시트), 슬라이드 1~3 = 국내 매칭 카드(스와이프 시작 시 지연
  로드). 카드 탭 → 스팟 상세. **유사도 수치는 노출하지 않는다**(순번만 — 과장
  방지). 당겨서 새로고침 = 새 seed 재셔플.
- **채널 스토리** — 타일 6종(`around·hot·hidden·festa·pets·snap`), 탭하면
  인스타형 스토리 뷰어(좌우 탭=카드, 스와이프=채널 전환, 아래=닫기). `around`만
  위치 권한 필요. 본 채널은 KST 일 단위 dim.
- **스팟 상세** — hero(갤러리 스트립 3+N) → 소개(`overview` verbatim, 5줄
  클램프) → 위치(카카오 미니맵·외부 지도 링크·정보행) → 공유/스크랩 → 주변
  추천 레일(3km, 12개). 미니맵은 비대화형 프리뷰이고, 탭하면 카카오 지도 앱으로
  나간다 — 앱 안에 별도 지도 화면은 없다.
- **스크랩** — 정렬·뷰 전환 없이 항상 2열 앨범. 타일 하트로 해제하고 토스트
  한 번으로 되돌린다.
- **인증** — OAuth 2종(kakao·apple)뿐. iOS 단독 출시라 App Store 4.8이 요구하는
  "동등한 대체 수단"을 Sign in with Apple이 담당한다. Kakao는 https 바운스
  (`pictrip.org/oauthredirect → pictrip://`), Apple은 네이티브
  `expo-apple-authentication`. 로그인 성공 시 동의 스냅샷 베스트에포트 기록.
  `/consent` 관리 화면은 구현돼 있으나 현재 진입 링크가 없다(미노출).

## 이미지 표시 규칙

`RemoteImage` 단일 컴포넌트가 담당한다:
- KTO 이미지의 하단 ~12% 워터마크 밴드는 **클라이언트 CSS 프레이밍**으로 프레임
  밖에 클립한다 — 파일 바이트 무변형이라 공공누리 Type 구분과 무관. 파일을
  변형하는 서버측 리사이즈는 Type1에만 발급된다(→
  [ADR-0005](../adr/0005-kto-image-policy.md)). 출처표시는
  `pictrip.org/legal/data-sources`가 전담한다 — 앱 안에는 출처 문구를 두지
  않는다.
- 폴백 체인: 원본(`_image1_1`) → 미드사이즈(`_image2_1`) → 직접
  Wikimedia(전용 UA) → 백오프 재시도 2회 → 회색 박스.
- blur-up(미드사이즈 블러 프리뷰 → 페이드인) + expo-image memory-disk 캐시.

## 설계 근거 / 트레이드오프

- **게스트 우선, 저장만 게이트** — 가입 마찰을 루프 밖으로 밀었다. 대가는
  개인화 신호가 늦게 쌓이는 것.
- **앱 내 지도 화면 없음** — 상세에서만 닿던 전용 지도 화면을 걷어내고 카카오
  지도 앱으로 넘긴다. 길찾기·주변 탐색은 지도 앱이 더 잘한다.
- **유사도 미표기** — 코사인 거리의 % 환산은 사용자를 오도한다. 신뢰는 결과
  품질로만 증명한다.
